Este repositorio tiene un proyecto de una aplicacion de musica con React Native, quiero implementar la funcion de que el usuario pueda crear una lista de reproducción personalizada. Y con la implementacion puesta el usuario deberia poder:
Crear una nueva playlist.
Asignarle un nombre.
Agregar canciones existentes de la aplicación.
Visualizar la playlist creada.
Mostrar las canciones que contiene.

Debe seguir las siguientes consideraciones:
Debe utilizar React Native Paper.
No utilizar una API externa.
No instalar nuevas librerías.
Reutilizar los componentes y datos existentes.
No eliminar funcionalidades actuales.
La playlist debe conservarse mientras el usuario navega por la aplicación.
